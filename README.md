# Ciddiyetle Şaka Yapan Bot

## Bu Nedir?

Bu, insanlık tarihinin en ciddi, en abartılı ve en gereksiz şaka üreticisidir. Şaka değildir. Gerçekten çalışır. Çalıştırmadığınız takdirde şaka üretmez. Bu bilimsel bir gerçektir.

Bu bot, hayatın anlamsızlığını ciddi bir şekilde şakaya çevirir. Veya şakayı ciddiye alır. Hangisi olduğunu kimse bilmiyor. Bilmek de istemiyoruz.

## Nasıl Çalıştırılır?

```bash
python saka_uretici.py
```

Çıktı örneği:
```
=== CİDDİYETLE ŞAKA YAPAN BOT v1.0 ===
Lütfen bekleyin, şaka üretiliyor...
Şaka: Kedi aslinda hic komik degildir. Gülün artık.

Bu şaka o kadar ciddiydi ki, gülmediyseniz sorun sizde.
```

Eğer gülmediyseniz, botun suçu değildir. Sizin mizah anlayışınız yeterince ciddi değildir.

## Özellikler

- Gerçekten çalışır
- Şaka üretir (veya üretmez, kim bilir)
- Aşırı ciddi
- Patates içermez
- Sonsuz değildir (ciddiyet sınırlıdır)

## Uyarı

Bu botu kullanmak hayatınızı değiştirmez. Ama belki de değiştirir. Değiştirmezse sorun değil. Değiştirirse de sorun değil. Her şey sorun değildir aslında. Ya da sorunludur. Kim bilir.
